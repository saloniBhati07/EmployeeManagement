# Employee Management System

## Project Description

A Java-based Employee Management System developed using JDBC and PostgreSQL.

## Technologies Used

- Java
- Maven
- JDBC
- PostgreSQL
- SQL
- SLF4J
- Logback
- Git
- GitHub

## Features

- Employee Management
- Department Management
- Add Employee
- View All Employees
- Search Employee
- Update Employee
- Delete Employee
- Input Validation
- Exception Handling
- Logging
- PostgreSQL Database Integration

## Project Architecture

- Model
- DAO
- Service
- Utility
- Exception
- Main

## Database

PostgreSQL is used as the database.
JDBC is used for database connectivity and CRUD operations.

## Logging

SLF4J and Logback are used for application logging.

## Build

The project is managed using Maven.

## How to Run

1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Configure PostgreSQL.
4. Update database credentials in DBConnectionUtil.
5. Run Maven build.
6. Run Main.java.
