# Task 10: Sprint 2 Mini Project Demo

## Project Name
Employee Management System

## Objective
Demonstrate the complete Employee Management System developed using Java, JDBC, PostgreSQL, Maven, SLF4J, and Logback.

## Features Demonstrated

- Department Management
- Employee Management
- Add Employee
- View All Employees
- Search Employee
- Update Employee
- Delete Employee
- PostgreSQL Database Integration
- Input Validation
- Exception Handling
- Logging

## Technologies Used

- Java
- Maven
- JDBC
- PostgreSQL
- SLF4J
- Logback
- Git

## Validation Rules

- Employee Name is mandatory
- Salary must be greater than ₹10,000
- Email format must be valid
- Department is required

## Logging

The application supports:

- INFO logs for successful operations
- WARN logs for validation issues and employee not found
- ERROR logs for database and application errors

## Database Integration

The application uses JDBC to connect with PostgreSQL and perform CRUD operations.

## Demo Result

The following operations were demonstrated successfully:

1. Add Employee
2. View All Employees
3. Search Employee
4. Update Employee
5. Delete Employee
6. Input Validation
7. Exception Handling
8. Logging
9. Database Integration

## Conclusion

The Sprint 2 Mini Project Demo was completed successfully.
The Employee Management System is integrated with PostgreSQL and supports employee CRUD operations, validation, exception handling, and logging.
